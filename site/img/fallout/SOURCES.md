# Referencia del Pip-Boy

`pipboy-original.png` es la imagen del menú de estado extraída sin retoques del
manual oficial de Fallout: New Vegas Ultimate Edition para PC, página impresa 7
(quinta página del PDF). Se utiliza para comparar la referencia visual del juego
con el ejercicio educativo. Fallout y su arte pertenecen a sus titulares.
